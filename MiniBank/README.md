# MiniBank

A simple banking system made with Python to practice programming logic.

Um sistema bancário simples feito em Python para praticar lógica de programação.

## Features | Funcionalidades

- Check balance | Consultar saldo
- Withdraw money | Sacar dinheiro
- Deposit money | Depositar dinheiro
- Validate withdrawals and deposits | Validar saques e depósitos

## Technologies | Tecnologias

- Python 3

## About | Sobre

**EN:** This is a beginner project I made to practice Python, conditional statements, user input, and basic calculations.

**PT-BR:** Este é um projeto de iniciante que fiz para praticar Python, estruturas condicionais, entrada de dados e cálculos básicos.

## How to run | Como executar

1. Make sure Python 3 is installed. / Certifique-se de que o Python 3 está instalado.
2. Clone this repository or download the files. / Clone este repositório ou baixe os arquivos.
3. Run the program. / Execute o programa:

```bash
python minibank.py
```
